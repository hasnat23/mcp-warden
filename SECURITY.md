# Security policy

mcp-warden is a defence-in-depth layer: it reduces risk from untrusted MCP servers but does not
make an untrusted server safe. Pattern-based detection can be evaded; allow lists and argument rules
are the controls that do not depend on detection.

To report a bypass or vulnerability, please open a private advisory at
https://github.com/hasnat23/mcp-warden/security/advisories/new rather than a public issue.
